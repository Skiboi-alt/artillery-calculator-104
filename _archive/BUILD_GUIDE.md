### 2️⃣ SMALL (Малый размер) ⭐ РЕКОМЕНДУЕТСЯ
- **Размер**: 50-65 MB
- **Оптимизация**:

  - Оптимизирована сборка подмодулей

  - Максимальная оптимизация Python
  - Может потребоваться компрессия UPX
- **Использование**: Когда критичен размер
- **Достоинства**: Самый маленький размер
- **Недостатки**: Может потребоваться доп. конфигурация

```bash

# Выберите вариант 3
```

## 🗜️ Оптимизация размера

### Встроенные методы

| Метод | Размер - | Сложность | Время |
|-------|----------|-----------|-------|
| `--strip` | 5-10% | Низкая | Быстро |
| `--optimize=2` | 3-7% | Низкая | Средне |
| `--onefile` | По сравнению с `--onedir` | Средняя | Быстро |

### Дополнительная оптимизация с UPX

UPX (Ultimate Packer for eXecutables) сжимает exe на 40-60%

#### Установка UPX
```bash
pip install upx-python
```

#### Использование в скрипте сборки
```python
args.append('--upx-dir=C:\\path\\to\\upx')
```

#### Примерные результаты
- Standard: 70-85 MB → 30-40 MB (с UPX)
- Small: 50-65 MB → 20-30 MB (с UPX)  
- Minimal: 30-45 MB → 12-18 MB (с UPX)

## 🎨 Иконка

### Проверка иконки
Файл `icon.ico` должен быть в папке проекта.

### Создание иконки (опционально)

#### Способ 1: Онлайн-конвертер
1. Перейдите на https://convertio.co/ru/png-ico/
2. Загрузите изображение PNG (256x256 рекомендуется)
3. Скачайте .ico файл
4. Переименуйте в `icon.ico`

#### Способ 2: Python
```python
from PIL import Image

img = Image.open('your_image.png')
img.save('icon.ico', format='ICO', sizes=[256, 256])
```

Требуется: `pip install Pillow`

## ❌ Решение проблем

### Проблема: "PyInstaller не найден"
```bash
# Решение:
pip install pyinstaller --upgrade
```

### Проблема: "Ошибка доступа к файлам"
```bash
# Решение 1: Запустите от администратора
# Решение 2: Проверьте права на папку
# Решение 3: Закройте все Python процессы
```

### Проблема: "Антивирус блокирует файл"
- Это нормально для новых exe файлов
- Добавьте исключение в антивирус
- При первом запуске файл будет проверен

### Проблема: "Медленный первый запуск"
- PyInstaller распаковывает файлы в %TEMP%
- Первый запуск занимает 5-30 секунд
- Последующие запуски будут значительно быстрее

### Проблема: "Требуется администратор"
- Это не требуется
- Проверьте права доступа к папке
- Переместите файл в другую папку

### Проблема: "Ошибка: Module not found"
Обновите скрипт сборки (добавьте модуль в `hidden_imports`):
```python
hidden_imports = [
    'tkinter',
    'tkinter.ttk',
    'tkinter.messagebox',
    'tkinter.simpledialog',
    'json',
    'math',
    'os',
]
```

## 🛠️ Дополнительно

### Создание ярлыка на рабочем столе

#### Windows
1. Кликните правой кнопкой по exe файлу
2. "Отправить" → "Рабочий стол (создать ярлык)"

#### Или вручную
1. Создайте файл `Calculator.lnk` с ссылкой на exe
2. Используйте командную строку:
```batch
mklink "C:\Users\User\Desktop\Calculator.lnk" "C:\Users\User\Desktop\Code\Art Comp\dist\Артиллерийский калькулятор 104-го ДОБ.exe"
```

### Изменение переменных окружения

Чтобы запускать из терминала из любой папки:
1. Добавьте папку `dist` в PATH
2. Windows + Pause → Advanced → Environment Variables
3. Добавьте путь к папке dist

### Повторная сборка

```bash
# Очистить старые файлы
python build_optimized.py
# Выберите вариант (все файлы build и dist будут удалены)

# Или вручную:
rmdir /s /q build dist
del *.spec
python build_optimized.py
```
