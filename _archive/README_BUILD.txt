✨ ОСНОВНЫЕ ПАРАМЕТРЫ ОПТИМИЗАЦИИ


Small режим (РЕКОМЕНДУЕТСЯ):
   • --strip              (удаляет отладочные символы)
   • --optimize=2         (максимальная оптимизация Python)
   • Экономия: 20-30% от базового размера
   • Результат: 50-65 MB (вместо 70-85 MB)
   • Полная функциональность: ДА


Minimal режим (для экономии):
   • Максимальная оптимизация
   • Экономия: 50-60% от базового размера
   • Результат: 30-45 MB
   • Полная функциональность: ДА


+ UPX (для экстремальной экономии):
   • Дополнительное сжатие exe
   • Экономия: еще 40-60%
   • Результат: 12-25 MB
   • Требует установки: pip install upx-python
   • Внимание: Может замедлить запуск

⚠️  ВОЗМОЖНЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ


Проблема: "ModuleNotFoundError: No module named 'pyinstaller'"
Решение:  pip install pyinstaller --upgrade

Проблема: "Permission denied" или "Access is denied"
Решение:  Запустите PowerShell от администратора

Проблема: "EXE файл не создается"
Решение:  1. Удалите папки build/ и dist/
          2. Удалите файлы *.spec
          3. Запустите заново

Проблема: Медленный первый запуск exe
Решение:  Нормально! PyInstaller распаковывает файлы в %TEMP%
          При повторных запусках будет быстрее

Проблема: Антивирус блокирует файл
Решение:  Нормально для новых exe файлов
          Добавьте в исключения антивируса
