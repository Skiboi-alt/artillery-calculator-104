📌 ТРИ СПОСОБА СБОРКИ
═══════════════════════════════════════════════════════════════

1️⃣  ИНТЕРАКТИВНАЯ (рекомендуется)
   python build_optimized.py
   → Выберите вариант 1, 2 или 3

2️⃣  БЫСТРАЯ (по умолчанию - режим Small)
   python build_fast.py
   → Сразу начинает сборку

3️⃣  ОРИГИНАЛЬНАЯ
   python build_exe.py.py
   → Старый скрипт


🎯 ВАРИАНТЫ РАЗМЕРА И ВРЕМЯ
═══════════════════════════════════════════════════════════════

  Standard    │  70-85 MB  │  1-2 мин  │ Без оптимизации
  Small ⭐    │  50-65 MB  │  2-3 мин  │ Рекомендуется
  Minimal     │  30-45 MB  │  3-4 мин  │ Для экономии места
  + UPX       │  -40-60%   │  +1 мин   │ Дополнительное сжатие


📋 ТРЕБОВАНИЯ
═══════════════════════════════════════════════════════════════

✓ Python 3.8+              pip --version
✓ PyInstaller              pip install pyinstaller --upgrade
✓ icon.ico в папке         (иконка приложения)
✓ Calculator.py в папке    (основной скрипт)


🚀 БЫСТРЫЙ СТАРТ (ДЛЯ БОЛЬШИНСТВА)
═══════════════════════════════════════════════════════════════

1. Откройте PowerShell в папке Art Comp
2. Выполните: python build_fast.py
3. Дождитесь завершения (2-3 минуты)
4. Найдите exe в папке: dist/
5. Тестируйте и распространяйте!


📁 РЕЗУЛЬТАТ
═══════════════════════════════════════════════════════════════

После сборки в папке dist/ найдете:
  Артиллерийский калькулятор 104-го ДОБ.exe
  └─ Это файл, который нужно распространять!


⚙️  ОПЦИИ ОПТИМИЗАЦИИ
═══════════════════════════════════════════════════════════════

Standard   → Без оптимизации, быстро, но большой размер
Small      → --strip + --optimize=2 (лучший выбор)
Minimal    → Максимальная оптимизация + UPX

Рекомендация: Small для 99% случаев


❌ ЧТО ДЕЛАТЬ ЕСЛИ ОШИБКА
═══════════════════════════════════════════════════════════════

"PyInstaller не найден"
→ pip install pyinstaller --upgrade

"Ошибка доступа"
→ Запустите PowerShell от администратора

"Ошибка модуля"
→ Обновите build_optimized.py (добавьте в hidden_imports)

"Медленный первый запуск"
→ Это нормально, PyInstaller распаковывает файлы


📊 ПРИМЕРНЫЕ РАЗМЕРЫ
═══════════════════════════════════════════════════════════════

Без оптимизации:    70-85 MB
С режимом Small:    50-65 MB    (экономия 20-30%)
С режимом Minimal:  30-45 MB    (экономия 50-60%)
Minimal + UPX:      12-20 MB    (экономия 80-90%)


🔍 ПРОВЕРКА УСТАНОВКИ
═══════════════════════════════════════════════════════════════

python --version
→ Должно быть 3.8+

pip list | findstr pyinstaller
→ Должно быть pyinstaller 6.x


💡 СОВЕТЫ
═══════════════════════════════════════════════════════════════

• Используйте режим Small если размер < 100 MB
• Для размера < 50 MB установите UPX
• При первом запуске exe может быть медленным
• Антивирус может блокировать файл - это нормально
• Сохраняйте файл в удобном месте


🎨 ИКОНКА
═══════════════════════════════════════════════════════════════

Файл: icon.ico должен быть в папке Art Comp

Если нет:
1. Найдите изображение (PNG, 256x256)
2. Конвертируйте онлайн: https://convertio.co/ru/png-ico/
3. Сохраните как icon.ico в папку проекта
