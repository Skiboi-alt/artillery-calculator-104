📈 ДЕТАЛЬНОЕ ОПИСАНИЕ КАЖДОГО ВАРИАНТА
════════════════════════════════════════════════════════════════

═══ ВАРИАНТ 1: STANDARD (Стандартная) ═══════════════════════
Описание:    Сборка без оптимизации
Размер:      70-85 MB
Скорость:    Самая быстрая сборка (1-2 мин)
Совместимость: 100% (максимальная)

Плюсы:
  ✓ Максимально быстрая сборка
  ✓ Максимальная совместимость
  ✓ Нет проблем с модулями
  ✓ Все отладочные данные сохранены

Минусы:
  ✗ Самый большой размер
  ✗ Медленнее при первом запуске
  ✗ Потребует больше места на диске

Когда использовать:
  • SSD с большим свободным местом
  • Отсутствуют ограничения по размеру
  • Требуется максимальная совместимость

Команда:
  python build_optimized.py → выбрать вариант 1


═══ ВАРИАНТ 2: SMALL (Малый размер) ⭐ ══════════════════════
Описание:    Оптимизированная сборка (РЕКОМЕНДУЕТСЯ)
Размер:      50-65 MB
Скорость:    Быстро (2-3 мин)
Совместимость: 99.9% (отлично)

Параметры оптимизации:
  --strip                      (удалить отладку)
  --optimize=2                 (максимум оптимизации)
  --collect-submodules=tkinter (оптимизировать модули)

Плюсы:
  ✓ Хороший баланс размер/функциональность
  ✓ Экономит 20-30% от базового размера
  ✓ Полная функциональность сохранена
  ✓ Нет проблем при запуске
  ✓ Из коробки готов к использованию

Минусы:
  ✗ Все еще занимает 50-65 MB
  ✗ Немного дольше сборка чем Standard

Когда использовать:
  • В 99% случаев (РЕКОМЕНДУЕТСЯ)
  • Стандартные диски с 100+ MB
  • Хотите баланс размер/функциональность

Команда:
  python build_fast.py
  или
  python build_optimized.py → выбрать вариант 2


═══ ВАРИАНТ 3: MINIMAL (Минимальный размер) ═════════════════
Описание:    Максимальная оптимизация
Размер:      30-45 MB
Скорость:    Медленнее (3-4 мин)
Совместимость: 99% (отлично)

Параметры оптимизации:
  --strip                      (удалить все отладочные данные)
  --optimize=2                 (максимальная оптимизация)
  --collect-submodules=tkinter
  --noupx                      (без компресии, готово к UPX)

Плюсы:
  ✓ Экономит 50-60% от базового размера
  ✓ Все еще полностью функционален
  ✓ Готов к дополнительной компрессии UPX
  ✓ Хороший для мобильных накопителей

Минусы:
  ✗ Требует дополнительное время на сборку
  ✗ Может потребоваться конфигурация

Когда использовать:
  • Критична экономия 20-30 MB
  • Раздача через интернет
  • Мобильные накопители (USB < 100 MB)

Команда:
  python build_optimized.py → выбрать вариант 3


═══ ВАРИАНТ 4: MINIMAL + UPX (Экстремальное сжатие) ══════════
Описание:    Максимальное сжатие exe файла
Размер:      12-25 MB
Скорость:    Медленнее (4-5 мин)
Совместимость: 99% (отлично)

Параметры оптимизации:
  --strip                      (максимум отладки удалено)
  --optimize=2                 (максимальная оптимизация)
  --collect-submodules=tkinter
  + UPX (Ultimate Packer for eXecutables)

Плюсы:
  ✓ Экономит 80-90% от базового размера
  ✓ Идеален для раздачи в интернете
  ✓ Помещается на старые CD диски
  ✓ Очень быстрая загрузка

Минусы:
  ✗ Требует установку UPX отдельно
  ✗ Может вызвать проблемы с антивирусом
  ✗ Упакованный exe медленнее при запуске
  ✗ Может потребоваться доп. конфигурация

Когда использовать:
  • Очень ограниченное место
  • Раздача через интернет (кредитные мегабайты)
  • Спецзадачи, требующие минимального размера

Установка UPX:
  pip install upx-python

Конфигурация в скрипте:
  # Добавьте в build_optimized.py:
  args.append('--upx-dir=C:\\path\\to\\upx')

Команда:
  python build_optimized.py → выбрать вариант 3


🔨 ПРОЦЕСС СБОРКИ
════════════════════════════════════════════════════════════════

1. Очистка (удаление старых сборок)
   └─ Удаляет: build/, dist/, *.spec

2. Проверка зависимостей
   └─ Проверяет: icon.ico, Python модули

3. Сборка с PyInstaller
   └─ Применяет: опции оптимизации
   └─ Время: 1-4 минуты (в зависимости от режима)

4. Создание exe файла
   └─ Путь: dist/Артиллерийский калькулятор 104-го ДОБ.exe

5. Генерация информации
   └─ Создает: BUILD_INFO.txt с информацией о сборке
