# Артиллерийский калькулятор 104-го ДОБ «Волчья стая»

Калькулятор возвышения для Молота (миномёта) и «Кувалды» в Arma 3 (RS:Q) по баллистическим таблицам.
Формулы и правила — по методичке «Обучение бойцов специализации AC (для 104-го ДОБ)».

## Скачать

**Windows:** готовый exe — в разделе [Releases](https://github.com/Skiboi-alt/artillery-calculator-104/releases/latest).
Python не нужен: скачайте и запустите. Сохранения появятся рядом с exe.

**Телефон (Android и iPhone):** откройте https://skiboi-alt.github.io/artillery-calculator-104/ и установите
на главный экран:
- Android (Chrome): кнопка «Установить» в приложении или меню ⋮ → «Добавить на главный экран»;
- iPhone (Safari): «Поделиться» → «На экран «Домой»».

После первого открытия приложение работает без интернета. Сохранения можно перенести с ПК:
«Сохранения» → «Импорт saves.json» (и обратно — «Экспорт»).

## Запуск из исходников

```bash
python Calculator.py
```

Нужен только Python 3.8+ со встроенным tkinter — сторонние библиотеки не требуются.

## Как пользоваться

1. Выберите орудие и заряд. Под зарядом — его дальность и шаг таблицы.
2. Введите дистанцию. Заряды, которые до неё не достают, приглушаются, а справа от подсказки
   написано, какие подходят.
3. Режим: **По таблице** — только дальности из таблицы; **Интерполяция** — любая дальность внутри диапазона заряда.
4. При необходимости включите **поправку на превышение** и введите высоты орудия и цели — поправляются
   и возвышение, и время полёта (4-й столбец таблицы: цель выше — прилёт раньше).
5. Нажмите **Рассчитать** или Enter.

Под результатом — **подсказки из методички**: перепад высот без поправки (рекомендуется от 50 м,
обязательно от 100 м), цель выше на 300 м и больше — для Молота нужен заряд 2, разброс до 20 м.

Под результатом видно, по каким строкам таблицы он получен, и строка **«Заряды»** — возвышение и время
полёта по всем подходящим зарядам (самый быстрый помечен; клик — выбрать заряд). Последние расчёты
собираются в **историю** — клик по строке возвращает её параметры.

**Корректировка огня** — после выстрела по докладу наблюдателя: «Недолёт» / «Перелёт» меняют дистанцию на шаг,
«Левее» / «Правее» сдвигают разрыв вбок; программа пересчитывает дистанцию и показывает поправку направления
в милах (6400 в круге) относительно линии орудие–цель.

**Таймер полёта** — клик по плитке «Время полёта» (или F2): обратный отсчёт до разрыва, сигнал за 5 секунд
и в момент разрыва. Справка — F1 или кнопка «?».

| Клавиши | Действие |
|---|---|
| Enter | Рассчитать |
| F2 | Таймер полёта (старт / стоп) |
| F1 | Справка |
| Ctrl+S / Ctrl+O | Сохранить / открыть сохранения (работает в любой раскладке) |
| Tab | Переход между элементами |
| ← / → | Переключение орудия, заряда, режима (когда выбран переключатель) |
| Пробел | Тумблер поправки, нажатие кнопки |

## Файлы рядом с программой

| Файл | Что хранит |
|---|---|
| `saves.json` | Именованные сохранения (до 10) |
| `settings.json` | Последние параметры, положение окна, историю |
| `calculator.log` | Журнал ошибок — пригодится, если что-то пошло не так |

Файлы пишутся безопасно: при сбое во время записи старая версия не портится. Повреждённый файл
не удаляется, а переименовывается в `*.broken`.

## Структура проекта

| Файл | Назначение |
|---|---|
| `Calculator.py` | Окно программы, точка входа |
| `ballistics.py` | Расчёт: таблица, интерполяция, поправка на превышение, корректировка огня |
| `field_rules.py` | Правила из методички: подсказки к результату, названия орудий |
| `weapons_data.py` | Баллистические таблицы (значения не менять) |
| `storage.py` | Сохранения, настройки, журнал |
| `version.py` | Номер версии и «Что нового» |
| `updater.py` | Проверка новой версии на GitHub |
| `ui_widgets.py` | Тема «Волчьей стаи» и компоненты интерфейса |
| `tests/` | Тесты расчёта, правил, версий и файлов |
| `mobile/` | Мобильная версия (PWA): `index.html`, `app.js`, `ballistics.js`, `field_rules.js`, `styles.css` |
| `mobile/data.js` | Таблицы, палитра, правила и версия для телефона — генерируются из Python-файлов |
| `tools/make_icon.py` | Генерация `icon.ico` и иконок телефона из эмблемы (нужен Pillow) |
| `tools/export_mobile.py` | Выгрузка данных в `mobile/data.js` |
| `tools/release_notes.py` | Описание релиза из `WHATS_NEW` |
| `.github/workflows/` | Публикация мобильной версии и сборка exe на GitHub |
| `_archive/` | Старые скрипты сборки, инструкции и прежняя иконка |

## Тесты

```bash
python -m unittest discover -s tests -v
```

Тесты мобильной версии — откройте `mobile/tests.html` в браузере или выполните `node mobile/tests/ballistics.test.js`.
На GitHub они запускаются автоматически перед каждой публикацией мобильной версии.

## Мобильная версия: разработка

```bash
python -m http.server 8104 --directory mobile
```

Затем откройте http://localhost:8104 (офлайн-кэш на localhost выключен; включить — `?sw=1`).
После изменения таблиц выполните `python tools/export_mobile.py`. После изменения файлов в `mobile/`
увеличьте `VERSION` в `mobile/sw.js` — так установленные приложения получат обновление.

## Сборка exe

```bash
pip install pyinstaller
```

```bash
python build.py
```

Скрипт сначала прогоняет тесты, затем собирает `dist/Артиллерийский калькулятор 104-го ДОБ.exe`.

## Выпуск новой версии

1. В `version.py` поднимите `APP_VERSION` и добавьте пункты в `WHATS_NEW`, в `CHANGELOG.md` — раздел версии.
2. `python tools/export_mobile.py` — версия попадёт и в мобильную версию; увеличьте `VERSION` в `mobile/sw.js`.
3. Закоммитьте и отправьте изменения, затем поставьте тег:

```bash
git tag v2.1.0
```

```bash
git push --tags
```

GitHub сам прогонит тесты, соберёт exe на Windows и создаст релиз с описанием из `WHATS_NEW`.
Программа для ПК раз в сутки проверяет релизы и показывает кнопку «Обновление», когда выходит новая версия.
Пробная сборка без релиза — Actions → «Сборка exe» → Run workflow.
