🔧 РАСШИРЕННЫЕ ВАРИАНТЫ ОПТИМИЗАЦИИ
════════════════════════════════════════════════════════════════════

Этот файл содержит примеры конфигурации для различных сценариев
оптимизации размера exe файла.


📌 КОГДА ИСПОЛЬЗОВАТЬ РАСШИРЕННЫЕ ОПЦИИ
════════════════════════════════════════════════════════════════════

Встроенные варианты (Small, Minimal) подходят для 99% случаев.
Расширенные опции используйте если:

• Размер уже < 50 MB и нужно еще меньше
• Требуется специальная конфигурация
• Приложение использует специфические модули
• Нужна максимально возможная оптимизация


🎯 ВАРИАНТЫ РАСШИРЕННОЙ ОПТИМИЗАЦИИ
════════════════════════════════════════════════════════════════════

═══ ВАРИАНТ A: ONEDIR + STRIP (Папка вместо одного файла) ════════

Размер:      35-50 MB (в одной папке)
Плюсы:       Немного меньше, быстрее сборка
Минусы:      Распространяется папка, не один файл

Модификация build_fast.py:
────────────────────────────
args = [
    'Calculator.py',
    f'--name={config["name"]}',
    '--onedir',              # ← ИЗМЕНЕНО с --onefile
    '--windowed',
    '--clean',
    '--noconfirm',
    '--strip',
    '--optimize=2',
]

Результат:
  dist/Артиллерийский калькулятор 104-го ДОБ/
  ├── Артиллерийский калькулятор 104-го ДОБ.exe
  └── (другие файлы и библиотеки)

Использование:
  1. Архивируйте папку в .zip
  2. При распаковке все работает
  3. Размер архива: 35-50 MB


═══ ВАРИАНТ B: UPX СЖАТИЕ (Дополнительная компрессия) ═════════════

Размер:      12-25 MB (с UPX)
Плюсы:       Экстремальное сжатие
Минусы:      Может замедлить запуск, требует UPX

Установка UPX:
────────────────────────────
pip install upx-python

Модификация build_optimized.py или build_fast.py:
────────────────────────────
# Добавьте перед запуском PyInstaller:

import shutil
from pathlib import Path

# Поиск UPX
upx_path = shutil.which('upx')
if not upx_path:
    print("⚠️  UPX не найден, пытаюсь установить...")
    os.system('pip install upx-python')
    upx_path = shutil.which('upx')

if upx_path:
    args.append(f'--upx-dir={os.path.dirname(upx_path)}')
    print(f"✓ Используется UPX: {upx_path}")

Результат:
  Размер exe: 12-25 MB (вместо 50-65 MB)
  Экономия: 75-85%

Важно:
  • Может вызвать ложные срабатывания антивируса
  • При запуске exe распаковывается в %TEMP%
  • Первый запуск может быть медленнее


═══ ВАРИАНТ C: ИСКЛЮЧЕНИЕ НЕНУЖНЫХ МОДУЛЕЙ ═══════════════════════

Если приложение не использует все модули Tkinter:

Размер:      На 5-10% меньше
Плюсы:       Меньше размер, быстрее сборка
Минусы:      Нужно знать какие модули не нужны

Модификация (добавьте в скрипт):
────────────────────────────
# Исключите неиспользуемые модули
exclude_modules = [
    'matplotlib',
    'numpy',
    'pandas',
    'PIL',
    'scipy',
    'sklearn',
]

for module in exclude_modules:
    args.append(f'--exclude-module={module}')

Для Calculator.py подходят:
  ✓ --collect-submodules=tkinter (уже используется)


═══ ВАРИАНТ D: ИСПОЛЬЗОВАНИЕ --STRIP ДОПОЛНИТЕЛЬНО ════════════════

Удаление различных символов отладки:

Модификация:
────────────────────────────
args = [
    'Calculator.py',
    f'--name={config["name"]}',
    '--onefile',
    '--windowed',
    '--clean',
    '--noconfirm',
    '--strip',               # Основной strip
    '--optimize=2',
    # Дополнительные опции для еще меньшего размера:
    '--remove-confirm',      # Удалить запросы подтверждения
]

Результат:
  Экономия дополнительно: 3-5%


═══ ВАРИАНТ E: КОМБИНИРОВАННАЯ ОПТИМИЗАЦИЯ ════════════════════════

Максимальное сжатие (размер 10-15 MB):

Что делать:
  1. Используйте --onedir (не --onefile)
  2. Добавьте UPX
  3. Применьте все опции strip
  4. Архивируйте в .zip или .7z

Примерный скрипт:
────────────────────────────
args = [
    'Calculator.py',
    '--name=Артиллерийский калькулятор 104-го ДОБ',
    '--onedir',              # Папка вместо файла
    '--windowed',
    '--clean',
    '--noconfirm',
    '--strip',
    '--optimize=2',
    '--collect-submodules=tkinter',
    # UPX если установлен
]

if upx_installed:
    args.append('--upx-dir=...')

Результат:
  1. Папка с exe: ~30-40 MB
  2. После архивации в 7z: ~10-15 MB
  3. После распаковки: работает как обычно


═══ ВАРИАНТ F: МИНИМАЛЬНЫЙ КОНСОЛЬ-РЕЖИМ ═════════════════════════

Если нужна консоль (для логирования):

Размер:      Чуть больше, чем windowed

Модификация:

args = [

    '--onefile',
    # '--windowed',       # ← ЗАКОММЕНТИРУЙТЕ ЭТУ СТРОКУ
    '--clean',
    '--noconfirm',
    '--strip',
    '--optimize=2',
]

Результат:
  При запуске exe появляется консоль с логами


═══ ВАРИАНТ G: ДЛЯ PORTABLE USB (ФЛЕШКА) ══════════════════════════

Для максимальной совместимости и переносимости:

Подход:
  1. Используйте режим --onedir
  2. Не используйте UPX (может быть несовместим)
  3. Архивируйте всю папку
  4. Распределяйте как zip файл

Скрипт:
────────────────────────────
args = [
    'Calculator.py',
    '--name=calc',           # Короче имя
    '--onedir',              # Для портативности
    '--windowed',
    '--clean',
    '--noconfirm',
    '--optimize=1',          # Меньше оптимизации
]

Результат:
  dist/calc/calc.exe
  └─ Работает на любой Windows
  └─ Размер папки: 40-50 MB
  └─ Архив: 20-30 MB

🔧 ПОШАГОВЫЙ ПРИМЕР: ОПТИМИЗАЦИЯ ДЛЯ ИНТЕРНЕТА
════════════════════════════════════════════════════════════════════

Цель: Максимальная оптимизация для интернет-распространения (< 25 MB)

Шаг 1: Установка инструментов
────────────────────────────
pip install pyinstaller --upgrade
pip install upx-python

Шаг 2: Создание оптимизированного скрипта
────────────────────────────
# Файл: build_internet.py
import PyInstaller.__main__
import os
import shutil

config = {
    'script': 'Calculator.py',
    'name': 'calc_soft',  # Короче имя
    'icon': 'icon.ico',
}

# Очистка
for folder in ['build', 'dist']:
    if os.path.exists(folder):
        shutil.rmtree(folder)

args = [
    config['script'],
    f'--name={config["name"]}',
    '--onedir',                           # Папка
    '--windowed',
    '--clean',
    '--noconfirm',
    '--strip',
    '--optimize=2',
    '--collect-submodules=tkinter',
    f'--icon={config["icon"]}',
    '--upx-dir=C:\\Program Files\\upx',  # Путь к UPX
]

for imp in ['tkinter', 'tkinter.ttk', 'json', 'math']:
    args.append(f'--hidden-import={imp}')

print("Сборка...")
PyInstaller.__main__.run(args)

# Архивирование
import zipfile
with zipfile.ZipFile(f'{config["name"]}.zip', 'w', zipfile.ZIP_DEFLATED) as zf:
    for root, dirs, files in os.walk(f'dist/{config["name"]}'):
        for file in files:
            file_path = os.path.join(root, file)
            arcname = os.path.relpath(file_path, 'dist')
            zf.write(file_path, arcname)

print(f"✓ Архив создан: {config['name']}.zip")

Шаг 3: Использование
────────────────────────────
python build_internet.py

Результат:
  calc_soft.zip (~15-20 MB)
  └─ Готов к интернет-распространению!


⚠️  ВАЖНЫЕ ЗАМЕЧАНИЯ
════════════════════════════════════════════════════════════════════

1. UPX и Антивирус
   └─ UPX упаковка может вызвать ложные срабатывания
   └─ Решение: добавить исключение в антивирус

2. Первый запуск UPX-упакованного exe
   └─ Медленнее, чем обычного (3-10 секунд)
   └─ Нормально, exe распаковывается в %TEMP%

3. --ONEDIR vs --ONEFILE
   └─ --onedir меньше по размеру
   └─ --onefile удобнее для распространения

4. Совместимость Python версии
   └─ Сборка на Python 3.11 работает на Python 3.11+
   └─ Для лучшей совместимости используйте Python 3.8-3.10

5. Исключение модулей
   └─ Будьте осторожны, может привести к ошибкам
   └─ Тестируйте exe после сборки
