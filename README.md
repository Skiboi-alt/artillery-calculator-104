# Артиллерийский калькулятор 104-го ДОБ «Волчья стая»

Калькулятор возвышения для миномёта и «Кувалды» в Arma 3 (RS:Q) по баллистическим таблицам.

## Скачать

Готовый exe для Windows — в разделе [Releases](https://github.com/Skiboi-alt/artillery-calculator-104/releases/latest).
Python не нужен: скачайте и запустите. Сохранения появятся рядом с exe.

## Запуск из исходников

```bash
python Calculator.py
```

Нужен только Python 3.8+ со встроенным tkinter — сторонние библиотеки не требуются.

## Как пользоваться

1. Выберите орудие и заряд. Под зарядом — его дальность и шаг таблицы.
2. Введите дистанцию. Заряды, которые до неё не достают, приглушаются, а справа от подсказки
   написано, какие подходят.
3. Режим: **По таблице** — только дальности из таблицы; **Интерполяция** — любая дальность внутри диапазона заряда.
4. При необходимости включите **поправку на превышение** и введите высоты орудия и цели.
5. Нажмите **Рассчитать** или Enter.

Под результатом видно, по каким строкам таблицы он получен. Последние расчёты собираются в **историю** —
клик по строке возвращает её параметры.

| Клавиши | Действие |
|---|---|
| Enter | Рассчитать |
| Ctrl+S / Ctrl+O | Сохранить / открыть сохранения (работает в любой раскладке) |
| Tab | Переход между элементами |
| ← / → | Переключение орудия, заряда, режима (когда выбран переключатель) |
| Пробел | Тумблер поправки, нажатие кнопки |

## Файлы рядом с программой

| Файл | Что хранит |
|---|---|
| `saves.json` | Именованные сохранения (до 10) |
| `settings.json` | Последние параметры, положение окна, историю |
| `calculator.log` | Журнал ошибок — пригодится, если что-то пошло не так |

Файлы пишутся безопасно: при сбое во время записи старая версия не портится. Повреждённый файл
не удаляется, а переименовывается в `*.broken`.

## Структура проекта

| Файл | Назначение |
|---|---|
| `Calculator.py` | Окно программы, точка входа |
| `ballistics.py` | Расчёт: таблица, интерполяция, поправка на превышение |
| `weapons_data.py` | Баллистические таблицы (значения не менять) |
| `storage.py` | Сохранения, настройки, журнал |
| `ui_widgets.py` | Тема «Волчьей стаи» и компоненты интерфейса |
| `tests/` | Тесты расчёта и файлов |
| `tools/make_icon.py` | Генерация `icon.ico` из эмблемы (нужен Pillow) |
| `_archive/` | Старые скрипты сборки, инструкции и прежняя иконка |
