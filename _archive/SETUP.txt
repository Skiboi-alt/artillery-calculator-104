1. build_fast.py ⭐ РЕКОМЕНДУЕТСЯ
   Быстрая сборка (режим Small - 50-65 MB)
   
   Использование: python build_fast.py
   Время: 2-3 минуты
   Размер: 50-65 MB
   
   ✓ Оптимальное соотношение размер/функциональность
   ✓ Готов к использованию из коробки

2. build_optimized.py

   Использование: python build_optimized.py

   Вариант 1: Standard (70-85 MB)
   Вариант 2: Small (50-65 MB) ⭐
   Вариант 3: Minimal (30-45 MB)

3. build_exe.py.py
   Оригинальный скрипт (для совместимости)
   
   Использование: python build_exe.py.py

✨ ПАРАМЕТРЫ ОПТИМИЗАЦИИ
════════════════════════════════════════════════════════════════════

Встроенные:
  --strip         (удалить отладку)        → -5-10%
  --optimize=2    (макс. оптимизация)      → -3-7%
  Итого с Small:  Экономия ~20-30%

Дополнительно:
  UPX             (компрессия exe)         → -40-60%

Варианты:
  Standard        Без оптимизации
  Small           --strip + --optimize=2 (рекомендуется)
  Minimal         Максимальная оптимизация
  Minimal + UPX   Экстремальное сжатие

⚠️ ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК
════════════════════════════════════════════════════════════════════

Ошибка: "ModuleNotFoundError: No module named 'pyinstaller'"
Решение: pip install pyinstaller --upgrade

Ошибка: "Permission denied" или "Access is denied"
Решение: Запустите PowerShell от администратора

Ошибка: "UPX is not installed"
Решение: pip install upx-python

Ошибка: "PermissionError: [WinError 32] The process cannot access the file"
Решение: Закройте все Python процессы и попробуйте снова

Ошибка: Exe файл не создается
Решение:
  1. Удалите папки build/ и dist/ вручную
  2. Удалите все .spec файлы
  3. Запустите сборку заново

Антивирус блокирует файл
Решение: Это нормально. Добавьте файл в исключения антивируса

Медленный первый запуск exe
Решение: PyInstaller распаковывает файлы в %TEMP%
         Это нормально, при повторных запусках быстрее

📚 ЧТО ДАЛЬШЕ?
════════════════════════════════════════════════════════════════════

После успешной сборки:

1. Тестирование:
   - Запустите exe файл
   - Проверьте все функции
   - Убедитесь что все работает

2. Для малого размера:
   - Прочитайте SIZE_OPTIMIZATION_GUIDE.txt
   - Выберите подходящий вариант
   - Пересоберите exe

3. Для распространения:
   - Скопируйте exe файл
   - Распространяйте через интернет или носитель
   - Пользователи могут запустить exe сразу

4. Для обновлений:
   - Отредактируйте Calculator.py
   - Пересоберите exe (просто запустите build_fast.py)
   - Распространяйте обновленный файл
