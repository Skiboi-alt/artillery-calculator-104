⚙️  ПАРАМЕТРЫ ОПТИМИЗАЦИИ
════════════════════════════════════════════════════════════════════════════════

Small режим (ПРИМЕНЯЕТСЯ В build_fast.py):
   ✓ --strip              удаляет отладочные символы
   ✓ --optimize=2         максимальная оптимизация Python
   → Экономия: 20-30% от базового размера
   → Результат: 50-65 MB вместо 70-85 MB
   → Функциональность: Полная

Minimal режим (ВЫБИРАЕТСЯ В build_optimized.py):
   ✓ Максимальная оптимизация
   → Экономия: 50-60% от базового размера
   → Результат: 30-45 MB
   → Функциональность: Полная

+ UPX (ДОПОЛНИТЕЛЬНОЕ СЖАТИЕ):
   ✓ Установка: pip install upx-python
   ✓ Сжатие exe файла
   → Экономия: еще 40-60%
   → Результат: 12-25 MB
   → Внимание: Может замедлить первый запуск
   → Внимание: Может вызвать ложные срабатывания антивируса

💡 ЧАСТО ЗАДАВАЕМЫЕ ВОПРОСЫ
════════════════════════════════════════════════════════════════════════════════

❓ Какой размер выбрать?
✅ Small (50-65 MB) для 99% случаев. Это оптимальное соотношение
   размер/функциональность/скорость.

❓ Почему первый запуск exe медленный?
✅ Это нормально! PyInstaller распаковывает файлы в %TEMP%.
   При повторных запусках будет быстрее.

❓ Почему антивирус блокирует файл?
✅ Это нормально для новых exe файлов. Добавьте исключение в
   антивирус или дождитесь проверки.

❓ Сколько времени займет сборка?
✅ Standard: 1-2 минуты
   Small:    2-3 минуты
   Minimal:  3-4 минуты
   +UPX:     4-5 минут

❓ Можно ли пересобрать после изменений?
✅ Да, просто снова запустите build_fast.py. Старые файлы
   будут автоматически удалены.

❓ Где найти готовый файл?
✅ В папке dist/
   Файл: "Артиллерийский калькулятор 104-го ДОБ.exe"

   └─ Щелкните правой кнопкой в папке → "Открыть PowerShell здесь"

   └─ "Артиллерийский калькулятор 104-го ДОБ.exe"

7. Протестируйте exe файл:
   └─ Двойной клик по файлу

⚠️  ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК
════════════════════════════════════════════════════════════════════════════════

Проблема → Решение:

"ModuleNotFoundError: pyinstaller"
→ pip install pyinstaller --upgrade

"Permission denied"
→ Запустите PowerShell от администратора

"EXE не создается"
→ Удалите вручную папки: build/ и dist/
  Удалите файлы: *.spec
  Попробуйте снова

"Медленный первый запуск"
→ Нормально! Это первая распаковка

"Антивирус блокирует"
→ Добавьте файл в исключения антивируса

Более подробные ответы в BUILD_GUIDE.md раздел "Решение проблем"
